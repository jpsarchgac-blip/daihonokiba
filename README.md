# 台本おき

Next.js と CodeMirror 6 で動く、プレゼン原稿の台本置き場アプリです。

## 使い方

1. `npm install`
2. `npm run dev` で [http://localhost:3000](http://localhost:3000) を開く
3. **編集**タブで原稿を貼り付け（文字数は全体・ページごとに表示）
4. **1分区切りを挿入**ボタン、または行単独の `=== 1分 ===` でページを分割
5. **プレビュー**タブで文字サイズ・行間・フォントを調整
6. **発表**タブで開始 — **1分ごと**に次のページへ自動切替

ヘッダーの **ダーク / ライト** でテーマを切り替えられます。編集タブの **ファイル** から JSON（設定込み）・TXT（原稿のみ）の入出力ができます。

### 操作（発表タブ）

- **スペース**: 開始 / 一時停止
- **← / →**: 前後のページ（手動）

発表時間は **ページ数 × 1分** です。原稿はブラウザの localStorage に自動保存されます。

### 音声追跡（任意）

マイクで読み上げ位置を追跡できます。**Chrome / Edge** 推奨。

## 技術スタック

- Next.js (App Router)
- React
- Tailwind CSS
- CodeMirror 6（`@uiw/react-codemirror`）
